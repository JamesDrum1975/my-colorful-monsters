# My Colorful Monsters — starter website

A responsive, static one-page website using the existing My Colorful Monsters logo, banner, character crew, playground artwork, and book artwork supplied from the brand's existing assets. No new monster characters have been invented.

## Preview locally
Open `index.html` in a web browser.

## Publish for free
1. Create a GitHub repository, for example `my-colorful-monsters`.
2. Upload `index.html` and the entire `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will provide the published URL after deployment.

## Before launch
- Replace the placeholder book button URL in `index.html` with the real Amazon/KDP product URL.
- Add a real print-ready coloring-page file and download link when you are ready to launch a free sample.
- Consider adding a parent-facing contact/newsletter form only when you choose a service and have its signup URL.
- Add a custom domain later if you decide it is worth the cost.

## Design choices
- Mobile-friendly, accessible HTML/CSS; no framework or paid service required.
- Character-led visual design, with the original brand artwork in the hero and character section.
- Clear book sales call to action, with placeholder links clearly marked.
- The site does not collect visitor data or use tracking scripts.
